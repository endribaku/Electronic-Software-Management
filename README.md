
# Electronic Software Management

A desktop application for managing retail store operations, including inventory, employees, suppliers, and sales performance.

## Overview

**Electronic Software Management** is a JavaFX-based system designed to help store managers and staff efficiently control every aspect of store management. The application allows you to:

- Track and organize inventory by sectors, categories, and items (e.g., electronics, furniture, peripherals).
- Manage suppliers and associate them with specific inventory items.
- Register, edit, and manage employees, assigning them roles, permissions, and sector responsibilities.
- Generate bills and keep records of sales transactions.
- Monitor employee performance with detailed statistics and visual charts for weekly, monthly, yearly, and total performance.
- Enforce user permissions for sensitive operations like inventory access, employee management, and bill generation.

## Key Features

- **Inventory Management**: Add, update, and track products, their categories, and quantities.
- **Supplier Management**: Assign and manage suppliers for each product or product category.
- **Employee Management**: Register new employees, set access levels (e.g., Manager, Cashier), and manage user data.
- **Billing System**: Generate and manage bills for sales, with record-keeping.
- **Performance Tracking**: Visualize employee sales performance across different periods.
- **Role-Based Access**: User permissions ensure secure access to sensitive features.
